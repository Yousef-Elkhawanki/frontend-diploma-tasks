CSS Challenges

Twelve real interfaces to build with HTML and pure CSS — no JavaScript, no framework, no preprocessor. Each challenge unlocks the next part of the CSS curriculum, and never asks for a concept you have not met yet.

How to use this module

  1. Work in order. Each challenge assumes the one before it.
  2. Read the brief — the README.md in the challenge folder — including the design reference image and the constraints.
  3. Build your own index.html and styles.css in your own folder, from the brief and the design reference alone.
  4. Only when you have finished, open the reference page, compare, and then read its stylesheet.
  5. Use your browser's developer tools on both pages. Inspecting the difference between your box model and the reference's is most of the learning.

The rules for this module

  • HTML for structure, external CSS for everything visual.
  • No <style> element and no style attribute.
  • No JavaScript, no Tailwind, no Bootstrap, no Sass, no UI library.
  • No concept from a later stage of the curriculum: if you have not met Flexbox yet, the challenge can be solved without it.
  • Every hover state needs a matching focus state, and every design decision has to survive being read by a screen reader.

Medium

CSS foundations: selectors, colour, backgrounds, borders, box model, units and spacing. No layout system yet — these pages are one column, in normal flow, which is exactly why the layout challenges later feel like a relief.

  • 01 — Riverbend Recycling Guide — selectors, colour, borders, a first stylesheet. 60–75 minutes. (brief for medium 01)
  • 02 — Fell Ridge Trail — backgrounds in depth, including fixed photographic bands and tiled textures. 75–90 minutes. (brief for medium 02)
  • 03 — Cogwheel Service Packages — box model, sizing, units, spacing rhythm, centring. 75–90 minutes. (brief for medium 03)
  • 04 — The Lantern Programme — everything above on one page, including a poster laid out with a background image. 90–105 minutes. (brief for medium 04)

Hard

How CSS actually behaves — the cascade, specificity and inheritance — then the tools that arrange a page: display, positioning, stacking and Flexbox.

  • 01 — Brackenfield Membership Form — cascade, specificity, inheritance, attribute selectors, field states. Styled without adding a single class. 90–120 minutes. (brief for hard 01)
  • 02 — Kilnworks Gallery Wall — display and normal flow, overflow, absolute badges, a sticky bar, stacking. 100–120 minutes. (brief for hard 02)
  • 03 — Loop Transport Landing Page — Flexbox: navbar, split hero, equal-height cards, media rows, footer. 100–120 minutes. (brief for hard 03)
  • 04 — Meridian Pricing — Flexbox, positioning and layering together: a raised plan, a ribbon, a wrapping add-on row. 110–130 minutes. (brief for hard 04)

Advanced

Two-dimensional layout, responsive design and modern CSS, finishing with a capstone that uses the entire module.

  • 01 — Halftone Print Catalogue — CSS Grid: spans, implicit tracks, minmax() and auto-fit, with no media query anywhere. 120–140 minutes. (brief for advanced 01)
  • 02 — Fairwater Property Listings — mobile-first responsive design, clamp(), aspect-ratio, object-fit, two honest breakpoints. 130–150 minutes. (brief for advanced 02)
  • 03 — Nocturne Streaming Browse — custom properties as a design system, pseudo-element decoration, transitions, transforms, animation and reduced motion. 130–150 minutes. (brief for advanced 03)
  • 04 — Signal Landing Page (capstone) — the whole module in one responsive page. 150–180 minutes. (brief for advanced 04)
