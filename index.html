How to use this repository

  1. Pick the next challenge you have not done. They get harder in order.
  2. Read its brief — the README.md in the challenge folder — from top to bottom.
  3. Build your own index.html in your own folder, from the brief alone.
  4. Only when you have finished, open the reference page and compare structure with structure.
  5. Then read the reference source. Where it differs from yours, work out which of you is right — sometimes it will be you.

Each brief starts with What You Will Practice, so you always know which concepts a challenge is drilling before you start it.

The rules

  • No CSS: no stylesheet, no <style>, no style attribute.
  • No JavaScript and no <script>.
  • No Tailwind, no Bootstrap, no component library.
  • No deprecated presentational elements.
  • Semantic elements where they carry meaning, plain HTML where it does not.
