Lumen desk chair size guide

All measurements are in centimetres, taken with the gas lift fully lowered.

Lumen frame sizes and recommended user height
Frame size Seat height Seat depth Backrest height Recommended user height
Small (A) 38–46 42 52 150–168 cm
Medium (B) 42–52 46 58 165–185 cm
Large (C) 46–56 50 63 182–200 cm

Between two sizes? Choose the smaller frame if you work at a desk lower than 72 cm, and the larger frame if you use a standing desk converter.
